# Per Azzurra, con amore

Sito statico per il diciottesimo di Azzurra. Il conto alla rovescia si sblocca il **3 ottobre 2026 alle 00:00 ora italiana (CEST, UTC+02:00)**. Non c'è pulsante né URL di anteprima per anticiparlo.

## Pubblicazione

Il deploy è automatico su GitHub Pages dal branch `main`: ogni push avvia il workflow `.github/workflows/pages.yml`. Il workflow pubblica la pagina, gli script, gli stili e l'album foto/video; non include la cartella anime né altri file di sviluppo.
